# 提取写作风格

从用户指定的中文文档中提取风格引例，按 8 个维度分析，每条引例打多个标签，输出 JSON 后导入 `style.db`。

## 输入参数

| 参数 | 必需 | 默认值 | 说明 |
|---|---|---|---|
| 文件路径（位置参数） | 否 | `**/*.txt` | 一个或多个文件路径，空格或逗号分隔，支持 glob |
| `--output` / `-o` | 否 | `./style_import.json` | 输出 JSON 路径 |

参数解析规则：
1. 未给路径 → glob `**/*.txt`
2. 路径是目录 → 递归收集所有 `.txt`
3. 不存在的文件 → 警告并跳过
4. 无有效文件 → 在 JSON 中写入错误信息
5. 输出目录不存在 → `mkdir -p`

## 执行流程

### 第一步：读取文件

解析/展开 glob，读取每个文件，记录文件名/行数/字符数，报告给用户。

### 第二步：逐维度分析

将所有文件视为一个语料库。以下 8 个维度逐一分析，**每个论断必须带原文引文**。

**2.1 叙事视角与叙述声音** — 人称、叙事距离、叙述者可靠性、视角一致性
**2.2 语言质地与句式节律** — 句长分布、段落结构、语域、节奏装置、用词偏好
**2.3 修辞手法与比喻系统** — 喻体来源域、核心隐喻、拟人/通感、意象、反讽
**2.4 人物对话与内心独白** — 引导语风格、角色语言辨识度、内心独白方式、潜台词
**2.5 描写密度与感官分配** — 五感+本体感觉、环境描写、身体描写、缩放级别、留白
**2.6 情感基调与氛围营造** — 主导基调、氛围技法（光/声/空间）、幽默、高潮特征
**2.7 时间处理与叙事节奏** — 场景/概述比、时间过渡、闪回、章节节奏、加减速位置
**2.8 篇章结构与信息控制** — 信息释放策略、章节首尾、悬念、主题编织

### 第三步：为每条引例打标签

每条引例必须带**至少 3 个标签**：
- 1 个维度标签（如 `人物对话与内心独白`、`句式节律`）
- 1 个泛化技法标签（如 `对话技巧`、`句式`、`叙事模式`）
- 1 个细化特征标签（如 `引导语省略`、`碎句断思`、`认知错位`）

**标签规则**：
- 标签可任意创建，鼓励交叉覆盖——宁可多打不可漏打
- 一个引例同时带有 `旁白叙事模式` 和 `叙事模式` 是**完全正确的**
- 风格指纹和可迁移技法直接以细化标签形式编码（如 `延迟反射`、`感官单通道优先`）
- 给每个有辨识度的技法起一个简洁的中文名称作为标签

**禁止使用**（除非有具体证据）：
"文笔流畅""描写生动""人物鲜明""情节紧凑""引人入胜"——这些是读者感受，不是风格特征。

### 第四步：输出 JSON

```json
{
  "source_files": ["file1.txt", "file2.txt"],
  "analyzed_at": "2026-08-12",
  "total_chars": 30000,
  "fragments": [
    {
      "fragment": "原文引用内容...",
      "dimension": "2.4",
      "note": "对话引导语极简，省略了说/道/问",
      "tags": ["对话技巧", "引导语省略", "人物对话与内心独白", "动作微缩替代", "叙事模式"]
    }
  ]
}
```

**关键**：JSON 中**不包含** `source_file` 和 `position` 字段——这些是参考数据，不需要标记来源。

### 第五步：导入 style.db

```bash
python novel-cli/cli.py style import style_import.json
```

这会将引例写入 `novel-cli/style.db`（工作区）。用户也可手动导入到根目录 `--db ../style.db` 供其他项目复用。

## 质量检查（输出前自查）

1. 每条引例至少 3 个标签
2. 无空洞评价词；每个论断有引文
3. 量化描述具体（"约60%"而非"多用"）
4. 引文是原文逐字复制，非转述
5. 细化标签有可辨识的命名
