# 01 — 初始化流程

## 1. 确定项目根目录

询问用户项目根目录（默认：当前工作目录）。

## 2. 获取创作需求

- 若用户在对话中直接提供了需求 → 将需求整理写入 `requirements.md`
- 若用户指定了需求文件路径 → 读取该文件
- 若用户未提供任何需求 → 询问用户创作方向（类型、主题、大致篇幅等），整理后写入 `requirements.md`

`requirements.md` 格式参考：
```markdown
# 创作需求
- **类型**：[奇幻/科幻/悬疑/...]
- **主题**：[核心主题]
- **篇幅**：[长篇/中篇，预计字数]
- **目标读者**：[受众描述]
- **特殊要求**：[用户提出的任何约束]
- **原始需求**：[保留用户原话]
```

## 3. 部署 CLI 工具并初始化项目骨架

将 skill 目录下的 `novel_cli.py` 和 `update_style.py` 复制到项目 `novel-cli/` 目录：

```bash
mkdir -p novel-cli
cp "<skill目录>/novel_cli.py" "<项目根目录>/novel-cli/cli.py"
cp "<skill目录>/update_style.py" "<项目根目录>/novel-cli/update_style.py"
cp "<skill目录>/output_style.py" "<项目根目录>/novel-cli/output_style.py"
```

然后初始化项目骨架（创建目录 + 数据库 + 风格库）：

```bash
python novel-cli/cli.py init .
```

初始化会自动创建：
- `novel-cli/entries/`（条目导出目录）
- `novel-cli/plots/L1/ L2/ L3/ L4/`（剧情文本目录）
- `novel-cli/log/latest.log`（当日日志）
- `novel-cli/novel.db`（SQLite 数据库，含 entries / dimensions / types / plot_nodes 表）
- `novel-cli/style.db`（风格库——若根目录有 style.db 则拷贝，否则创建空库）
- `contents/`（正式正文产出目录）

## 4. 登记内置类型

素材库的类型是自由的（见 guide 02），但建议在初始化时先登记一批常用类型，让后续 agent 有共同的词汇：

```bash
python novel-cli/cli.py type add entry character "角色：有独立意志与成长弧的人物"
python novel-cli/cli.py type add entry location  "地点：故事发生的场所"
python novel-cli/cli.py type add entry item      "道具：对剧情有作用的具体物件"
python novel-cli/cli.py type add entry concept   "概念：世界观设定/抽象事物/伏笔"
python novel-cli/cli.py type add entry scene     "场景模型：反复出现或需要固定布局的场所"
python novel-cli/cli.py type add dimension 身份   "角色身份与社会关系"
python novel-cli/cli.py type add dimension 外貌   "外观描述"
python novel-cli/cli.py type add dimension 性格   "性格特征与行为模式"
python novel-cli/cli.py type add dimension 场景模型 "空间布局、物件方位等固定描述"
python novel-cli/cli.py type add dimension 伏笔   "伏笔的埋设/揭示状态与条件"
```

后续 agent 创建新类型/新维度时，必须先 `type add` 登记含义。

## 5. 检查风格库

若 `novel-cli/style.db` 存在（初始化时已自动处理）→ 跳过。

若用户有参考风格数据但尚未导入 → 提醒用户先用 `extract-writing-style` 技能从已有文稿生成，然后运行 `update-style` skill 或 `python novel-cli/update_style.py` 同步。

## 6. 写初始化日志

```bash
python novel-cli/cli.py log append 初始化 创建 requirements.md "需求已录入"
python novel-cli/cli.py log append 初始化 部署 novel-cli/ "项目骨架已初始化"
```
