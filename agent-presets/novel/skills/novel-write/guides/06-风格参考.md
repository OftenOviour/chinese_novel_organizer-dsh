# 06 — 风格参考

## style.db 的作用

`style.db` 存储了从参考文本提取的风格引例，按**多标签**索引。agent 通过标签检索快速定位需要的风格参考，而不是通读整个 style.md。

## 工作区与参考数据

- `novel-cli/style.db`：工作区风格库，所有 CLI `style` 命令操作此文件
- `../style.db`：根目录参考数据（由 extract-writing-style 生成），只读
- 根目录更新后运行 `python novel-cli/update_style.py` 或 `/update-style` 同步

## 特征规则层（style rule）

引例告诉你"像什么"，**规则告诉你"做什么 / 避免什么"**——写 L4 时规则比引例更直接。每条规则关联一个证据引例：

```bash
# 添加规则（keep=该保持的做法 / weaken=该削弱的毛病）
python novel-cli/cli.py style rule add keep "多用短句制造紧张" --ref 12
python novel-cli/cli.py style rule add weaken "避免过度修饰形容词" --note "删璀璨/瑰丽类词"

# 查看规则（写作前注入）
python novel-cli/cli.py style rule list                 # 全部
python novel-cli/cli.py style rule list --action keep   # 只看保持规则

# 删除规则
python novel-cli/cli.py style rule del 2
```

**规则从哪来**：extract-writing-style 分析引例时提炼；或 agent 写作中发现可迁移的技法时手动添加。规则库随引例一起维护。

## L4 写作前的必读流程

```
# 0. 注入特征规则（★ 先做——规则比引例更直接）
python novel-cli/cli.py style rule list

# 1. 快速概览（有哪些维度、多少引例）
python novel-cli/cli.py style overview

# 2. 根据当前场景需要的技巧搜标签
python novel-cli/cli.py style search --tags "对话" --limit 5

# 3. 读具体引例
python novel-cli/cli.py style get 12

# 4. 需要更多参考时扩展（通过共享标签发现相关引例）
python novel-cli/cli.py style expand 12 --limit 10
```

写作时：按 KEEP 规则做、按 WEAKEN 规则避；不确定的细节再查引例。

## 不确定时的处理

如果在写作中对某方面风格不确定（如"这里该用长句还是短句""对话引导语该详细还是简洁"）：

```
# 按维度缩小范围
python novel-cli/cli.py style list --dimension 2.2

# 或按标签搜
python novel-cli/cli.py style search --tags "句式,短句" --any
```

不要凭记忆猜测——**检索 style.db，不是通读**。

## style.db 不存在时

1. 提醒用户：`style.db 不存在。建议先用 extract-writing-style 技能从已有文稿生成风格库。`
2. 如果用户选择不生成 → 按照通用高质量中文小说行文标准来写，并在日志中备注
3. 也可以先创建空库：`python novel-cli/cli.py style init`，后续手动追加引例

## 写作中发现新的风格模式

如果写 L4 时发现参考库中没有的风格特征，追加自定义引例：

```bash
python novel-cli/cli.py style add \
    --source "contents/1/1_1_序卷.txt" \
    --dimension 2.2 \
    --position "第45-48行" \
    --tags "句式节律,碎句断思,新发现" \
    --fragment "原文引例..." \
    --note "风格分析说明"
```

**source 和 position 必填**——这些是自定义引例，需要标记来源以便追溯。

## 浏览技巧

```bash
# 看所有标签及频次
python novel-cli/cli.py style tags

# 只看某维度
python novel-cli/cli.py style tags --dimension 2.4

# 列出所有有来源的引例（自定义的）
python novel-cli/cli.py style list --source

# 按维度列出
python novel-cli/cli.py style list --dimension 2.4
```

## 注意事项

- style.db 中的引例描述的是**已有文稿**的风格，新章节不必 100% 复制，但应保持可辨识的风格连续性
- 如果新章节有意改变风格（如换视角、换节奏），在日志中备注
- 标签可任意创建，鼓励交叉覆盖——搜索时多打几个标签提高命中率
