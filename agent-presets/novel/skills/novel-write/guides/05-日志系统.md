# 05 — 日志系统

## 概述

日志使用纯文本 `.log` 文件，位于 `novel-cli/log/`。CLI 工具统一管理写入格式和轮转。

## 日志轮转

每次 `log append` 自动检测是否需要轮转，无需手动干预。也可手动轮转：

```bash
python novel-cli/cli.py log rotate           # 非当天则轮转
python novel-cli/cli.py log rotate --force   # 强制轮转
```

轮转逻辑：
- 检查 `latest.log` 的修改日期
- 不是今天 → 重命名为 `YYYY-MM-DD.log` → 新建空白 `latest.log`
- 是今天 → 跳过
- 文件不存在 → 新建

## 追加日志

```bash
python novel-cli/cli.py log append <层级> <操作类型> <目标> <备注>
```

示例：
```bash
python novel-cli/cli.py log append L3 创建 plots/L3/1/3_瓦朗坦出发 "瓦朗坦出发寻找阿利斯戴尔"
python novel-cli/cli.py log append 素材库 修改 character.瓦朗坦.性格 "新增：冲动"
python novel-cli/cli.py log append L4 发布 contents/1/1_1_序卷 "用户确认后发布正文"
```

### 层级取值
`初始化` `L1` `L2` `L3` `L4` `素材库` `修订`

### 操作类型取值
`创建` `修改` `确认` `删除` `查询` `发布` `部署` `跳级`

## 查看日志

```bash
# 查看今天（latest.log）
python novel-cli/cli.py log show --tail 20     # 最新 20 行
python novel-cli/cli.py log show               # 全部

# 查看指定日期
python novel-cli/cli.py log show --date 2026-08-04

# 查看今天
python novel-cli/cli.py log show --today
```

## 多 agent 协作

不同 agent 通过日志文件同步进度：

1. **新 agent 启动时** → `python novel-cli/cli.py log show --tail 20` 了解最新状态
2. 根据日志中最后一条记录的层级和文件，直接继续工作
3. 不需要读取所有历史日志（除非需要追溯决策背景）

---

日志内容保持**简洁**——只记录"做了什么"，详细内容在剧情树和素材库中。每日一个 `.log` 文件，自动轮转。
